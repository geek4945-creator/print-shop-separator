Image tools

Open a photo here, or switch over after you pick one for the print package.

Films are spot-color separations for a shop, not a photograph. Back art is upscaled with tiled Real-ESRGAN when the model loads, otherwise Lanczos. Chest lettering is Kaushan Script, SIL Open Font License.

Install the app: Android APK (allow unknown sources) or Windows installer (SmartScreen → More info → Run anyway; the build is unsigned). Look for print-shop-separator.apk and Print-Shop-Separator-Setup.exe on a version tag such as v1.0.0.
